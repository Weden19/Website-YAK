# Website-YAK
VRChat Yakovlev academy group's website

## Регистрация на турнир

Форма находится по адресу `/tournament/`. Для записи заявок в Google Sheets:

1. Создайте или откройте таблицу Google и выберите **Расширения → Apps Script**.
2. Замените содержимое редактора кодом из `google-apps-script/Code.gs` и сохраните проект.
3. Выберите **Развернуть → Новое развертывание → Веб-приложение**. Запускать от имени нужно владельца таблицы; доступ установите «Все».
4. Разверните веб-приложение и скопируйте URL, заканчивающийся на `/exec`.
5. В `js/tournament.js` присвойте этот URL константе `GOOGLE_APPS_SCRIPT_URL` и опубликуйте изменения сайта.

При первой заявке скрипт автоматически создаст лист «Регистрация на турнир». Форма останется выключенной, пока URL веб-приложения не настроен. Поскольку endpoint общедоступен, используйте отдельную таблицу с ограниченными правами доступа и не храните в ней секретные данные.
